## 📌 Project Overview

The **HorizonTechX Language Translation Tool** is a web-based application that allows users to translate text between multiple languages.

The application provides a simple and user-friendly interface where users can:

- Select a source language
- Select a target language
- Enter text to translate
- Translate the text with one click
- View the translated output instantly

The project uses **Python, Streamlit, and an NLP-based translation API**.
